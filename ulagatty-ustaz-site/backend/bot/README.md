# Telegram-бот приёма статей + чека

Бот спрашивает у автора ФИО → контакт → категорию → тему → текст (или файл)
→ фото (необяз.) → **чек об оплате**, сохраняет заявку в Directus
(`publish_requests`), а админу присылает карточку с кнопками
**«✅ Жариялау / ❌ Бас тарту»**. По «Жариялау» создаётся **черновик статьи**
в коллекции `articles` (ты его потом публикуешь в админке).

Работает через **long polling** — публичный адрес/вебхук НЕ нужен, HTTPS для
бота не требуется. Бот поднимается тем же `docker compose`, что и Directus.

---

## 1. Создать бота у @BotFather
1. В Telegram открой **@BotFather** → `/newbot`.
2. Задай имя и username (должен заканчиваться на `bot`, напр. `ulagatty_bot`).
3. BotFather пришлёт **токен** вида `8123456:AAE...` — это `BOT_TOKEN`.

## 2. Узнать свой ADMIN_CHAT_ID
Это нужно, чтобы заявки приходили лично тебе.
1. Пока без настройки запусти бота (шаг 4) и напиши ему в личку **`/id`** —
   он ответит числом. Это `ADMIN_CHAT_ID`.
   (Либо временно оставь пустым, добавишь после первого запуска и пересоберёшь.)

## 3. Статический токен Directus для бота
Бот пишет в Directus под отдельным доступом.
1. Админка Directus → **Settings → Access Policies → New Policy** →
   назови `bot`, дай права **Create/Read/Update** на коллекции
   `publish_requests`, `articles` и на **Directus Files** (Create).
2. **User Directory → Create User** (напр. `bot@ulagattyustaz.kz`),
   назначь ему политику `bot`.
3. Открой этого пользователя → поле **Token** → **Generate** → скопируй.
   Это `DIRECTUS_TOKEN`.
   (На первое время можно взять токен администратора — но для продакшена
   лучше отдельный пользователь.)

## 4. Заполнить .env и запустить
В `~/backend/.env` впиши:
```
BOT_TOKEN=8123456:AAE...
ADMIN_CHAT_ID=123456789
DIRECTUS_TOKEN=токен_из_шага_3
```
Пересобери и подними контейнеры:
```bash
cd ~/backend
docker compose up -d --build
docker compose logs -f bot        # должно появиться "Бот запущен (long polling)"
```

## 5. Проверка
1. Открой своего бота в Telegram → **/start** → **/post**.
2. Пройди шаги (ФИО, контакт, категория, тема, текст, фото, чек).
3. Тебе (ADMIN_CHAT_ID) прилетит карточка заявки с кнопками.
4. Нажми **✅ Жариялау** → в Directus (`articles`) появится черновик,
   автору уйдёт уведомление.
5. В админке опубликуй черновик (status = published) → статья появится на сайте.

## Команды бота
- `/post` — подать статью
- `/cancel` — отменить заполнение
- `/id` — показать твой chat id

## Память (1 ГБ RAM)
Бот лёгкий (`mem_limit: 150m`). Directus (~400 МБ) + бот (~80 МБ) + swap
вмещаются в 1 ГБ. Если станет тесно под нагрузкой — апгрейд до 2 ГБ.

## Если что-то не так
```bash
docker compose logs --tail=50 bot      # логи бота
docker compose restart bot             # перезапуск
```
Частые причины: неверный `BOT_TOKEN`, не создан `DIRECTUS_TOKEN`/политика,
или ещё не созданы коллекции (`bash setup-collections.sh`).
