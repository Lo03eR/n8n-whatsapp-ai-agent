# Перенос материалов со старого сайта (ulagatttyustaz.kz)

Старый сайт — на **WordPress** (тема Neve). Его REST API открыт публично,
поэтому **все статьи и картинки выгружаются без логина и пароля.**

## Шаг 1. Выгрузить контент — выбери любой способ

### Способ 1 (проще всего, БЕЗ установок, любая ОС) — через браузер
1. Открой сайт: **https://ulagatttyustaz.kz**
2. Нажми **F12** → вкладка **Console** (Консоль)
3. Открой файл `export_console.js`, скопируй весь код, вставь в консоль, **Enter**
4. Через пару секунд сам скачается файл **articles.json** (все статьи с текстом)

> Картинки при этом не скачиваются — но в JSON есть ссылки на них.
> Для картинок используй Способ 2 или 3.

### Способ 2 (Windows, БЕЗ установок) — PowerShell (встроен в Windows)
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\export_wp.ps1
```
Скачает статьи, страницы **и картинки** в папку `export/`.

### Способ 3 (если есть Python 3)
```bash
cd ulagatty-ustaz-site/tools
python3 export_wp.py
```

Появится папка `export/`:
```
export/
├── articles.json      # все статьи: заголовок, дата, slug, категории, текст(HTML), картинка
├── pages.json         # статические страницы (О нас, Контакты и т.п.)
├── categories.json    # категории
└── images/            # все скачанные изображения (featured + внутри текста)
```

Доп. опции:
```bash
python3 export_wp.py --no-images          # без картинок (быстрее)
python3 export_wp.py --site https://ulagatttyustaz.kz --out export
```

> Скрипт сам проходит все страницы API (`?per_page=100&page=N`), скачивает
> картинки и переписывает ссылки в тексте на локальные `images/...`.

## Шаг 2. Куда заливать — два реальных пути

### Вариант A (рекомендуется): оставить WordPress, сменить только дизайн
Сайт уже на WordPress со всей механикой (публикация, админка, SEO, статьи).
Проще всего **не переносить контент вообще**, а применить новый дизайн
к самому WordPress — сделать из этого макета **тему WordPress** (или
настроить текущую тему Neve под новый вид). Тогда все 100+ статей,
публикация и админка остаются на месте. Минус: нужен доступ в админку/хостинг.

### Вариант B: перенести контент на новый сайт
Нужен бэкенд/CMS (чтобы работала публикация и оплата). Варианты:
- поднять **новый WordPress** и импортировать `articles.json` (плагином
  импорта или WP-CLI) — дизайн ставим как тему;
- либо сделать **свой бэкенд** и залить `articles.json` в базу;
- либо, если статьи почти не меняются, **сгенерировать статические страницы**
  из `articles.json` под текущий HTML-макет (подходит как витрина, но
  публикация/оплата всё равно потребуют бэкенда).

## Когда всё-таки нужен логин/хостинг
Только для: полной базы, настроек, оригиналов файлов, и чтобы **менять тему**
на действующем сайте. Как вернуть доступ:
- «Забыли пароль» на странице входа (если есть доступ к e-mail аккаунта);
- панель хостинга (cPanel/ISPmanager) → phpMyAdmin → сброс пароля/экспорт БД;
- тот, кто делал сайт, или регистратор домена.
