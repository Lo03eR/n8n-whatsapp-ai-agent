# Ұлағатты Ұстаз — сайт (обновлённый дизайн)

Свежий редизайн информационно‑образовательного портала для педагогов
(https://ulagattyustaz.kz). Весь функционал существующего сайта сохранён,
дизайн переработан глобально: зелёно‑золотая казахская тема, орнаменты,
адаптив, плавные анимации и **переключение языка ҚАЗ / РУС**.

Сайт статический — чистый **HTML + CSS + JavaScript**, без сборки и зависимостей.
Открывается двойным кликом по `index.html` или с любого хостинга.

## Структура папки

```
ulagatty-ustaz-site/
├── index.html          # Главная (герой, курсы, статьи, видео, форум, календарь, CTA)
├── courses.html        # Курсы повышения квалификации + фильтр по категориям
├── articles.html       # Статьи/материалы педагогов + публикация
├── subscription.html   # Тарифы + загрузка чека об оплате (как в будущем боте)
├── certificate.html    # Генератор сертификатов с уникальным номером документа
├── contact.html        # Контакты + FAQ (аккордеон)
├── login.html          # Вход / Регистрация (личный кабинет)
├── css/
│   └── styles.css      # Вся дизайн‑система (цвета, компоненты, адаптив, печать)
└── js/
    ├── i18n.js         # Словарь переводов ҚАЗ/РУС + логика переключения
    ├── layout.js       # Общая шапка и подвал (вставляются на все страницы)
    └── main.js         # Интерактив: меню, табы, FAQ, календарь, генератор, формы
```

## Как запустить локально

Просто откройте `index.html` в браузере. Либо поднимите мини‑сервер:

```bash
cd ulagatty-ustaz-site
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Реализованный функционал

- **Переключение языка ҚАЗ / РУС** — весь текст переводится мгновенно,
  выбор сохраняется в браузере (`localStorage`). Новые тексты добавляются
  в один файл `js/i18n.js`.
- **Курсы и статьи** — карточки с фильтром по категориям
  (Мектепке дейінгі, Бастауыш сынып, Орта білім, Тіл және әдебиет,
  Цифрлық сауаттылық и т.д.).
- **Подписка и оплата** — три тарифа и форма с **загрузкой чека**
  (drag‑and‑drop). Это веб‑версия того же сценария, что будет у бота:
  пользователь присылает чек → админ проверяет → публикация + сертификат.
- **Генератор сертификатов** (`certificate.html`) — повторяет макет из
  присланного PDF (красный «CERTIFICATE», синее ФИО, зелёная тема,
  золотая рамка, печать‑уголок, QR‑код). Три типа документа:
  **сертификат / благодарственное письмо / праздничное поздравление**.
  **Каждый раз генерируется новый уникальный регистрационный номер**
  (формат `№A0001535 - 02B`). Кнопка «Печать / PDF» выводит чистый бланк.
- **Форум, видеоматериалы, календарь событий, поиск** — как на оригинале.
- **Адаптив** — корректно отображается на телефоне, планшете и десктопе,
  мобильное меню «бургер».

## Дорожная карта (следующие этапы — по запросу)

Сайт уже спроектирован под будущую интеграцию. Что нужно сделать дальше:

1. **Бэкенд/БД** — хранение пользователей, статей, платежей, сертификатов.
2. **Telegram + WhatsApp бот** (на базе n8n — уже есть в этом репозитории):
   - пользователь присылает **фото статьи + чек об оплате**;
   - бот пересылает чек **админам**; админ **подтверждает / отклоняет**;
   - при подтверждении — автопубликация статьи и **выдача сертификата
     с уникальным номером** (логика номера уже есть в `js/main.js` →
     `genCertNumber()`, её легко перенести на сервер).
3. **Гибкая цена** — админ может менять стоимость публикации в любой момент
   (поле цены вынести в настройки/БД; на сайте цены в `subscription.html`).
4. **Праздничные поздравления** — рассылка пользователям по праздникам
   (бот + генератор типа «Құттықтау», тип документа уже заложен).
5. **Генерация сертификатов на сервере** в PDF (например, Puppeteer/pdf‑lib)
   по тому же макету, что в `certificate.html`.

> Текущая задача — **только сайт**. Бот и серверная часть делаются отдельно,
> когда дадите отмашку. Макет сертификата и сценарий оплаты уже совпадают
> с будущим ботом, поэтому переход будет бесшовным.
