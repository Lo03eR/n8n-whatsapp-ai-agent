# Ұлағатты Ұстаз — сайт (обновлённый дизайн)

Редизайн **информационного портала для педагогов** ulagatttyustaz.kz.
Структура и функционал повторяют оригинал (новостной портал со статьями
по категориям), дизайн переработан глобально: современная зелёно‑золотая
казахская тема, слайдер, карточки, адаптив и **переключение языка ҚАЗ / РУС**.

Сайт статический — чистый **HTML + CSS + JavaScript**, без сборки.
Открывается двойным кликом по `index.html` или с любого хостинга.

## Структура папки

```
ulagatty-ustaz-site/
├── index.html          # Главная портала:
│                        #  • Басты жаңалықтар — слайдер-карусель
│                        #  • боковой список главных новостей
│                        #  • Соңғы жаңалықтар — лента + сайдбар «Көп оқылған»
│                        #  • секции-категории: Ұстаз, Мектеп тынысы, Тәрбие
│                        #  • рекламные баннеры
├── category.html       # Лента категории/архив (?c=ustaz|school|tarbie|method) + фильтр
├── article.html        # Отдельная статья (фото, мета, текст, цитата, «поделиться», похожие)
├── publish.html        # «Мақала жариялау» — отправка статьи + чек оплаты (сценарий будущего бота)
├── certificate.html    # Генератор сертификатов с уникальным номером (как в PDF)
├── contact.html        # Контакты + FAQ
├── login.html          # Вход / Регистрация
├── css/styles.css      # Дизайн-система + компоненты портала (слайдер, карточки, баннеры)
├── data/               # Контент портала (демо/офлайн-источник)
│   ├── articles.sample.json  # демо-данные (переименуйте экспорт в articles.json)
│   └── README.md             # как подключить реальные статьи
├── backend/            # Бэкенд: Directus (CMS = база + API + админка)
│   ├── docker-compose.yml    # запуск Directus на SQLite (лёгкий, под 1 ГБ RAM)
│   ├── nginx-api.conf        # reverse proxy для api.<домен>
│   ├── SCHEMA.md             # какие коллекции создать в Directus
│   └── README.md             # пошаговая установка на VPS
└── js/
    ├── config.js       # UU_API — адрес бэкенда (пусто = локальный data/articles.json)
    ├── i18n.js         # Словарь переводов ҚАЗ/РУС
    ├── layout.js       # Общая шапка (логотип, поиск, меню, язык) и подвал
    ├── content.js      # Наполнение сайта статьями (Directus API → иначе data/articles.json)
    └── main.js         # Слайдер, меню, поиск, формы, календарь, генератор сертификата
```

## Бэкенд (Directus)

Серверная часть — в папке `backend/` (headless CMS **Directus**: база данных,
REST API и админка). Сайт берёт статьи из API, если в `js/config.js` задан
`window.UU_API`; иначе — из локального `data/articles.json`. Установка на
VPS — `backend/README.md`, список коллекций — `backend/SCHEMA.md`.

## Реальные статьи (data/articles.json)

Сайт **сам наполняется** статьями из `data/articles.json` — слайдер, ленты,
разделы по категориям и страницы статей (`article.html?slug=…`). Выгрузите
статьи инструментами из `tools/` и положите `articles.json` в папку `data/`.
Файла нет — показываются демо-карточки, ничего не ломается. Подробности —
`data/README.md`. Запускать через мини-сервер (`python3 -m http.server`),
чтобы `fetch` смог прочитать файл.

## Как запустить локально

Откройте `index.html` в браузере. Либо мини‑сервер:

```bash
cd ulagatty-ustaz-site
python3 -m http.server 8000     # http://localhost:8000
```

## Что ещё реализовано (по вашим пожеланиям)

- **Переключение ҚАЗ / РУС** — весь текст переводится мгновенно, выбор
  сохраняется (`localStorage`). Все строки в `js/i18n.js`.
- **Публикация статьи** (`publish.html`) — форма: тема, категория, автор,
  текст, фото + **загрузка чека об оплате**. Это веб‑версия сценария бота:
  прислал статью и чек → админ проверяет → публикация + сертификат.
- **Генератор сертификатов** (`certificate.html`) — повторяет макет из
  присланного PDF (красный «CERTIFICATE», синее ФИО, зелёная тема, золотая
  рамка, печать-уголок, QR). Типы: сертификат / благодарность / **поздравление**.
  **Каждый раз новый уникальный рег. номер** (`genCertNumber()` в `main.js`).

## Дорожная карта (следующие этапы)

Текущая задача — **только сайт**. Дальше (по отмашке):

1. **Бэкенд/БД** — статьи, пользователи, платежи, сертификаты; админка.
2. **Telegram + WhatsApp бот** (n8n уже в этом репозитории): пользователь
   шлёт фото статьи + чек → бот пересылает админам → подтверждение/отклонение
   → автопубликация + сертификат. Админ меняет цену в любой момент.
3. **Праздничные поздравления** — рассылка пользователям (тип «Құттықтау» готов).
4. **Серверная генерация PDF‑сертификатов** по макету `certificate.html`.

> переименовать в `js/i18n.js` и `js/layout.js`.
