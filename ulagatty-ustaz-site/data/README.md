# Данные сайта — articles.json

Сайт **сам наполняется** статьями из файла `data/articles.json`.

## Как подключить реальные статьи

1. Выгрузите статьи со старого сайта любым способом из `../tools/`
   (проще всего — `tools/export_console.js` через консоль браузера).
2. Положите полученный **`articles.json`** сюда, в папку `data/`
   (рядом с этим README), заменив демо-файл.
3. Откройте сайт через мини-сервер (важно — не двойным кликом):
   ```bash
   cd ulagatty-ustaz-site
   python3 -m http.server 8000     # затем http://localhost:8000
   ```
   Слайдер, ленты, разделы категорий и страницы статей заполнятся
   автоматически. Если файла нет — сайт покажет демо-карточки (ничего
   не ломается).

## Формат

`articles.json` — это массив статей. Одна статья:

```json
{
  "id": 123,
  "title": "Заголовок статьи",
  "slug": "zagolovok-stati",
  "date": "2026-10-13T08:00:00",
  "link": "https://ulagatttyustaz.kz/...",
  "categories": ["Ұстаз"],
  "excerpt_html": "<p>Краткое описание…</p>",
  "content_html": "<p>Полный текст статьи в HTML…</p>",
  "featured_image": "https://ulagatttyustaz.kz/wp-content/uploads/..."
}
```

## Как статьи попадают в разделы

Раздел определяется по полю `categories` (поиск по подстроке, регистр не важен).
Правила — в `js/content.js`, объект `CAT_RULES`:

| Раздел сайта    | Метки категорий (примеры)                    |
|-----------------|----------------------------------------------|
| Ұстаз           | ұстаз, педагог, мұғалім, учитель             |
| Мектеп тынысы   | мектеп, школ, тыныс                          |
| Тәрбие          | тәрбие, рухани, воспит, құттықтау            |
| Әдістеме        | әдістеме, метод, сабақ, технология           |

Категорию, которой нет в таблице, легко добавить — допишите метку в нужный
список в `CAT_RULES`.

> `articles.sample.json` — демонстрационный файл (условные тексты), чтобы
> проверить, что всё работает. Переименуйте ваш реальный экспорт в
> `articles.json` — он имеет приоритет.
