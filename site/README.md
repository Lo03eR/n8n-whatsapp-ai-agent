# Зона отдыха «ЭДЕМ» — демо-сайт

Многостраничный демонстрационный сайт для городской зоны отдыха **«Эдем»** в Шымкенте
(ул. Сайрамская, 192/1). Атмосфера — райский уголок с водой, зеленью и восточным гостеприимством.

## Страницы

| Файл | Раздел |
|------|--------|
| `index.html` | Главная — обзор, фичи, прайс, отзывы |
| `pools.html` | Бассейны — взрослая и детская аквазона |
| `cafe.html` | Кухня и кафе — меню, мангал, восточная кухня |
| `hotel.html` | Гостиница — номера, круглосуточное заселение |
| `events.html` | Банкеты — дни рождения, корпоративы, торжества |
| `gallery.html` | Галерея — фотоатмосфера комплекса |
| `contacts.html` | Контакты — адрес, телефоны, карта, форма брони |

## Как открыть

Это статический сайт без сборки. Просто откройте `index.html` в браузере
или поднимите локальный сервер:

```bash
cd site
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Технологии

- Чистый HTML5 + CSS3 (дизайн-система в `assets/css/style.css`)
- Ванильный JS (`assets/js/main.js`): sticky-хедер, бургер-меню,
  анимации появления, демо-форма бронирования
- Шрифты Google Fonts (Playfair Display + Manrope)
- Адаптивная вёрстка (десктоп / планшет / мобильный)
